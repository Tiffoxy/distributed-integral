\# Мой проект: Распределенный калькулятор



\## Что это?

Программа, которая считает интегралы на нескольких компьютерах сразу.



\## Как собрать?

Открой файлы в Visual Studio и нажми F5.



\## Как запустить?

1\. Сначала запусти server.cpp

2\. Потом запусти client.cpp в других окнах



\## Что я делала?

\- Сервер раздает задачи клиентам

\- Чем больше ядер у клиента, тем больше работы он получает

\- Все результаты суммируются

\- Есть логирование в файл
